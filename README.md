# Terminal Atlas

Terminal Atlas 是一个正在规划中的命令行知识产品，目标是通过可随时查阅的卡片和低干扰的重复展示，帮助用户熟悉常用命令。

## 当前状态

仓库目前只有产品规格和开发说明，**尚无可运行的 Web 应用**。第一阶段计划实现 Vite、React 和 TypeScript Web demo；Tauri 2 桌面集成属于后续阶段。
