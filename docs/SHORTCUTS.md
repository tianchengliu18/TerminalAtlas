# Keyboard shortcuts

All card shortcuts are disabled while typing in input fields, textareas, selects, contenteditable elements, code editors, native dialog fields and during IME composition. System shortcuts keep their normal behavior. Every action also has a clickable control.

| Key | Action |
| --- | --- |
| `↑ ↓ ← →` | Move through the visible card grid |
| `1` | Toggle frequent; independent of mastery |
| `2` | Toggle mastered; clears often forgotten |
| `3` | Toggle often forgotten; clears mastered |
| `0` | Clear learning marks; retain favorite and notes |
| `Enter` | Open the selected command details |
| `Space` | Switch a card between overview and flag breakdown |
| `F` | Toggle favorite |
| `P` | Pin or unpin for Ambient |
| `C` | Copy the first example |
| `/` or `⌘K` / `Ctrl+K` | Focus search |
| `?` | Open shortcut help |
| `Esc` | Close an overlay or drawer |
